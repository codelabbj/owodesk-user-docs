# Facturation électronique MECeF (Bénin)

Au **Bénin**, OwoDesk émet des factures normalisées conformes au dispositif **MECeF / e-MCF** de la **DGI**.

- Configuration : **Paramètres → Facturation** (panneau e-MECeF / DGI). Voir [Fiscal / e-facture](/modules/facturation/fiscal-efacture).
- Finalisation normalisée : [Factures](/modules/facturation/factures).

Fiche produit : [Facturation MECeF Bénin](https://www.owo.bj/facturation-mecef-benin)

:::warning Périmètre
MECeF en production = **Bénin**. Ne pas écrire que la facturation électronique est live dans les 17 pays OHADA.
:::

Pour une capture d'une facture certifiée (QR / référence DGI), utiliser une **vraie** facture de démo — pas un mock inventé.
