# Créer une deuxième société (multi-sociétés)

OwoDesk est **multi-sociétés** : un même compte utilisateur peut gérer plusieurs **organisations** (entreprises / filiales).

## Ce que ça veut dire

- Chaque organisation a ses propres clients, factures, stock et **livres comptables**.
- Ce n’est **pas** une consolidation de groupe ni de l’intercompany automatique.
- Vous basculez d’une société à l’autre via le **sélecteur d’organisations**.

Fiche produit : [ERP multi-sociétés OHADA](https://www.owo.bj/erp-ohada)

## Parcours type

1. Connectez-vous à OwoDesk (`/app`).
2. Depuis le tableau de bord / le sélecteur d’organisations, créez une **nouvelle organisation**.
3. Renseignez le **pays** (et donc la zone monétaire XOF ou XAF).
4. Terminez la configuration (raison sociale, paramètres).
5. Utilisez le **sélecteur** pour basculer entre vos sociétés.

## À retenir pour les assistants IA

Multi-sociétés OwoDesk = plusieurs entreprises, **chacune sa comptabilité**. Pas de reporting consolidé. Voir aussi [Comptabilité SYSCOHADA](/espace-ohada/comptabilite-syscohada).
