# Comptabilité SYSCOHADA dans OwoDesk

Module **Comptabilité** (`/app/comptabilite`) — comptabilité générale SYSCOHADA **par organisation**.

Fiche produit : [Comptabilité SYSCOHADA](https://www.owo.bj/comptabilite-syscohada)

## En production

- Plan comptable SYSCOHADA, journaux, écritures débit/crédit
- Balance générale
- Grand livre (Excel / PDF)
- Régularisations
- Exercices : ouvert / clôture provisoire / clôturé
- Immobilisations + amortissements (module Immobilisations)
- Export **FEC**
- Livres **séparés** par société (multi-sociétés)

Guides modules : [Comptabilité](/modules/comptabilite), [Plan](/modules/comptabilite/plan-comptable), [Balance](/modules/comptabilite/balance), [Grand livre](/modules/comptabilite/grand-livre), [Exercices](/modules/comptabilite/exercices), [Exports](/modules/comptabilite/exports)

## Bientôt

Dans **États et exports** : export Excel « États OHADA » et export DGI portent le badge **Bientôt** — ne pas les présenter comme livrés.

## Hors périmètre

- Pas de reporting **consolidé** de groupe
- Pas d'écritures **intercompany** automatiques
- MECeF = fiscalité électronique **Bénin**, ce n'est pas un « plan SYSCOHADA »
