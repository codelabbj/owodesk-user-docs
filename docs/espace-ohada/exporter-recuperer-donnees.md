# Exporter / récupérer ses données

Les données métier restent la **propriété du client** (CGU). OwoDesk permet d'exporter sans promettre un SLA inventé.

## Comptabilité

- **FEC** : disponible (`/app/comptabilite/exports`)
- **Grand livre** : export Excel / PDF
- États OHADA Excel et DGI : encore **Bientôt** dans l'app

Voir [États et exports](/modules/comptabilite/exports) et la fiche [SYSCOHADA](https://www.owo.bj/comptabilite-syscohada).

## Autres modules

Selon les écrans : exports Excel/CSV pour clients, produits, listes métier (imports Excel aussi côté premiers pas / stock / CRM selon le module).

## Réversibilité

Vous pouvez récupérer vos écritures (FEC) et grands livres pour un cabinet ou une migration. Pas de consolidation de groupe à exporter : chaque organisation a ses propres livres.
