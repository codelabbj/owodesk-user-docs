# Pays, monnaie (XOF/XAF) et espace OHADA

OwoDesk est un ERP **multi-pays** pour l'espace OHADA. **Une organisation = un pays** (et une monnaie associée).

## 17 États membres (pas 19)

Bénin, Burkina Faso, Cameroun, Centrafrique, Comores, Congo, Côte d'Ivoire, Gabon, Guinée, Guinée-Bissau, Guinée équatoriale, Mali, Niger, République démocratique du Congo, Sénégal, Tchad, Togo.

## Monnaie

Selon le pays de l'organisation : **XOF** ou **XAF**. La comptabilité suit le plan **SYSCOHADA** partout.

## Fiscalité électronique

- **MECeF (DGI) en production = Bénin.**
- Autres pays : même plateforme, déploiement fiscal **progressif** (ne pas écrire que e-facture est live dans les 17 pays).
