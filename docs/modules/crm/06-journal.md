# Journal

Onglet **Journal** (`/app/crm/journal`).

:::info Propriétaire
Visible pour le **propriétaire** (et profils équivalents). Journal d’**audit** des actions CRM.
:::

Filtres typiques : période / dates. Consultez l’historique des actions sensibles pour le contrôle interne.

Ce n’est pas le même écran que les **activités commerciales** (appels, emails) gérées depuis l’[Accueil](/modules/crm/accueil) ou les fiches.
