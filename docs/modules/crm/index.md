# CRM

Le module **CRM** (`/app/crm`) centralise entreprises, contacts, pipelines et affaires commerciales.

Sous-titre dans l’app : *Entreprises, contacts, pipelines de vente, affaires et activités.*

| Onglet dans l’app | Documentation |
|-------------------|---------------|
| **Accueil** | [Accueil (pipeline)](/modules/crm/accueil) (bureau) |
| **Entreprises** | [Entreprises](/modules/crm/entreprises) |
| **Contacts** | [Contacts](/modules/crm/contacts) |
| **Pipelines** | [Pipelines](/modules/crm/pipelines) (bureau) |
| **Vue 360°** | Voir [Vue 360°](/modules/crm/vue-360) — la synthèse se consulte sur les **fiches** entreprise / contact |
| **Journal** | [Journal](/modules/crm/journal) (propriétaire) |

Sur mobile, l’ouverture du module peut aller directement vers **Contacts** (Accueil / Pipelines masqués selon l’écran).

## Parcours type

1. Configurez vos [pipelines](/modules/crm/pipelines) et étapes.
2. Créez [entreprises](/modules/crm/entreprises) et [contacts](/modules/crm/contacts).
3. Gérez les affaires sur l’onglet [Accueil](/modules/crm/accueil) (Kanban).
4. Ouvrez une fiche pour la [vue 360°](/modules/crm/vue-360) (facturation, commercial, activités, projets…).

## Pages hors menu

Les routes `/app/crm/dashboard`, `/app/crm/deals` et `/app/crm/activities` peuvent exister mais **ne figurent pas** dans les onglets. Le travail quotidien se fait surtout depuis **Accueil** et les fiches.
