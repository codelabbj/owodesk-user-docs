# Vue 360°

La synthèse client **360°** se consulte sur les **fiches** :

- [Entreprise](/modules/crm/entreprises) → `/app/crm/companies/{id}` ;
- [Contact](/modules/crm/contacts) → `/app/crm/contacts/{id}`.

:::info Onglet Vue 360°
L’onglet **Vue 360°** peut encore apparaître dans la barre du module, mais la consultation utile se fait via les fiches ci-dessus (plus de page autonome avec sélecteur d’entreprise comme avant).
:::

## KPI

| Indicateur | Signification |
|------------|---------------|
| **Pipeline** | Affaires en cours |
| **Facturé** | Montant facturé |
| **Encaissé** | Montant payé |
| **Reste dû** | Solde |
| **Impayés en retard** | Créances en retard |

## Sous-onglets

| Sous-onglet | Contenu |
|-------------|---------|
| **Synthèse** | Vue résumée |
| **Facturation** | Factures (lien vers Facturation) et paiements ; états de règlement |
| **Commercial** | Affaires, devis, commandes vente |
| **Activités** | Historique d’activités |
| **Projets** | Si le module Projets est actif |
| **Contacts** | Sur fiche **entreprise** uniquement : contacts rattachés |

Sur une fiche **contact**, une bannière peut proposer **Voir la fiche entreprise**.
