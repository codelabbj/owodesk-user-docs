# Annulations

Onglet **Annulations** (`/app/pos/cancellations`). Titre : **Annulations contrôlées**.

Sous-titre : *Annulez des ventes avec motif obligatoire — toutes les annulations sont auditees.*

## Ventes annulables

Liste des ventes finalisées récentes (souvent jusqu’à 30) : Vente, Client (**Anonyme** si besoin), Montant, **Annuler**.

## Annuler une vente

Modale **Annuler la vente #…** :

- rappel : action irréversible, auditée, restitution de stock ;
- **Motif d'annulation** * (obligatoire) ;
- **Confirmer l'annulation**.

## Journal des annulations

Historique : Vente, Montant (−), Motif, **Annulé par**, Date.

Le journal d’audit détaillé (owner) est aussi dans [Activités](/modules/pos/activites).
