# Exercices

Écran **Exercices comptables** (`/app/comptabilite/exercices`).

L’exercice courant **encadre la saisie** : hors période ou exercice clôturé = refus des écritures.

## Actions

| Action | Effet |
|--------|-------|
| **Ouvrir un exercice** | Crée une période (souvent 1er janv. – 31 déc.) |
| **Définir comme courant** | Exercice de référence pour la saisie (un seul) |
| Afficher / utiliser la période | Applique les dates au filtre des rapports |
| **Clôturer** | Verrouille : plus d’écriture sur cette période |

Statuts : **Ouvert** / **Clôturé**, badge **Courant**.
