# Plan comptable

Écran **Plan comptable SYSCOHADA** (`/app/comptabilite/plan-comptable`).

Référentiel OHADA UEMOA pour votre organisation.

## Actions

- Consulter / rechercher les comptes ;
- **Ajouter un compte** ;
- **Réimporter le référentiel OHADA** (réinitialisation / complétion du plan).

Une bannière indique le nombre de comptes actifs. Si le plan est incomplet, une alerte apparaît sur le [tableau de bord](/modules/comptabilite/tableau-de-bord).
