# Stock

Le module **Stock** (`/app/inventory`) gère vos produits, entrepôts, quantités, mouvements et achats fournisseurs.

Sous-titre dans l’app : *Produits, entrepôts, niveaux de stock et mouvements.*

Ouvrez-le depuis le menu latéral **Stock**. Le sous-menu reprend les onglets de l’application :

| Onglet dans l’app | Documentation |
|-------------------|---------------|
| **Accueil** | [Accueil](/modules/stock/accueil) |
| **Produits** | [Produits](/modules/stock/produits) |
| **Catégories** | [Catégories](/modules/stock/categories) |
| **Entrepôts** | [Entrepôts](/modules/stock/entrepots) |
| **Niveaux de stock** | [Niveaux de stock](/modules/stock/niveaux-stock) |
| **Transferts** | [Transferts](/modules/stock/transferts) (bureau) |
| **Mouvements** | [Mouvements](/modules/stock/mouvements) |
| **Achats** | [Achats](/modules/stock/achats) (bureau) |
| **Autorisations** | [Autorisations](/modules/stock/autorisations) (propriétaire) |
| **Activités** | [Activités](/modules/stock/activites) (propriétaire) |

## Parcours type

1. Créez vos [catégories](/modules/stock/categories), [produits](/modules/stock/produits) et [entrepôts](/modules/stock/entrepots).
2. Définissez les [niveaux de stock](/modules/stock/niveaux-stock) (quantités et seuils).
3. Enregistrez les [mouvements](/modules/stock/mouvements) ou [transferts](/modules/stock/transferts).
4. Réapprovisionnez via les [achats](/modules/stock/achats).

## Limites actuelles

- **Transferts** et **Achats** sont prévus pour un usage **bureau** (pas pleinement mobile).
- Les pages **Réapprovisionnement** et **Étiquettes** existent en URL mais **ne sont pas** dans la navigation du module.
- L’inventaire physique se fait dans **Niveaux de stock** (sous-onglet), pas comme onglet séparé.
