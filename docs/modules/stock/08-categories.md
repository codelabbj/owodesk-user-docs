# Catégories

Onglet **Catégories** (`/app/inventory/categories`). Titre : **Catégories produits**.

Organisez le catalogue en arbre (catégorie parente + sous-catégories).

## Nouvelle catégorie

Bouton **Nouvelle catégorie** :

| Champ | Description |
|-------|-------------|
| **Nom** | Obligatoire |
| **Catégorie parente** | Ou **— Racine (aucun parent)** |
| **Description** | Optionnel |

## Arbre

Pour chaque catégorie :

- compteur de produits ;
- **Voir les produits** ;
- **Ajouter une sous-catégorie** ;
- modifier / supprimer.

Les produits se rattachent à une catégorie depuis [Produits](/modules/stock/produits).
