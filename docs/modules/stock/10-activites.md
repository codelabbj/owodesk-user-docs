# Activités

Onglet **Activités** (`/app/inventory/activities`). Titre : **Activités stock**.

:::info Propriétaire
Visible pour le **propriétaire** (journal d’audit du module).
:::

Suivez les actions sensibles (mouvements, achats, etc.) pour le contrôle et l’historique.

Menu latéral **Stock** → **Activités**.
