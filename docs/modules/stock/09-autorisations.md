# Autorisations

Onglet **Autorisations** (`/app/inventory/access`).

:::info Propriétaire
Visible pour le **propriétaire** de l’organisation.
:::

## Accès aux entrepôts

Pour chaque **collaborateur** : liste des **entrepôts autorisés**.

- **+ Ajouter un entrepôt…**
- **Retirer l'accès**

Un collaborateur ne voit / n’utilise en général que les entrepôts qui lui sont ouverts.

## Confirmation des bons de commande

Colonne / option **Peut confirmer les BC**.

Le propriétaire est **Toujours autorisé**. Les autres collaborateurs doivent être explicitement habilités pour confirmer une commande fournisseur.
