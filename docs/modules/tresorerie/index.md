# Trésorerie

Le module **Trésorerie** (`/app/treasury`) suit les **flux opérationnels** : caisse, banque, revenus, dépenses, impayés et rapports de cash.

Sous-titre dans l’app : *Flux opérationnels : caisse, revenus, dépenses et rapports.*

:::info Ancien nom
Ce module s’appelait autrefois **Comptabilité** (`/app/accounting`). L’ancien chemin redirige vers **Trésorerie**.  
La **comptabilité générale SYSCOHADA** (plan, écritures, balance) est un module séparé : [Comptabilité](/modules/comptabilite).
:::

## Parcours type

1. Consultez la [vue d'ensemble](/modules/tresorerie/vue-ensemble).
2. Suivez les comptes caisse/banque dans [Caisse & banque](/modules/tresorerie/caisse-banque).
3. Analysez [revenus](/modules/tresorerie/revenus) et [dépenses](/modules/tresorerie/depenses).
4. Pilotez les impayés via [dettes & créances](/modules/tresorerie/dettes-et-creances).
5. Exportez depuis les [rapports](/modules/tresorerie/rapports).

## Bureau

Le module est prévu pour un usage **ordinateur** (pas pleinement mobile).
