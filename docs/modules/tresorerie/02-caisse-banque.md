# Caisse & banque

Onglet **Caisse & banque** (`/app/treasury/treasury`).

Suivi des comptes de trésorerie (caisse, banques) et des mouvements.

## Contenu typique

- Cartes de soldes (**Entrées** / **Sorties**) ;
- **Historique des transactions** ;
- **Virement Interne** entre comptes ;
- Clic sur un compte pour le détail.

:::info
Dans l’ancienne doc, cet écran s’appelait l’onglet « Trésorerie » du module Comptabilité.
:::
