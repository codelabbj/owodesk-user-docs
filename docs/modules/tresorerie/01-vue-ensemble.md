# Vue d'ensemble

Onglet **Vue d'ensemble** (`/app/treasury/dashboard`). Titre : **Tableau de bord trésorerie**.

## Indicateurs

| Indicateur | Signification |
|------------|---------------|
| **Trésorerie Totale** | Solde global caisse / banque |
| **Revenus (Mois)** | Encaissements du mois |
| **Dépenses (Mois)** | Décaissements du mois |

## Alertes

- Factures à encaisser ;
- Fournisseurs à payer.

## Autres blocs

- **Flux de trésorerie (30j)** ;
- **Activité récente**.
