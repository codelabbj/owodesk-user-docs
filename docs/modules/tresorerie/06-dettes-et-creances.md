# Dettes & créances

Onglet **Dettes & Créances** (`/app/treasury/debts`).

## Contenu

- Créances **clients** (impayés) ;
- Dettes **fournisseurs** ;
- **Dettes envers les associés** (liées aux apports / comptes associés) ;
- Filtre **Retards seulement**.

Utile pour prioriser les encaissements et les paiements fournisseurs.
