# Dépenses

Onglet **Dépenses** (`/app/treasury/expenses`). Titre : **Gestion des Dépenses**.

## Actions

- **Nouvelle dépense** ;
- Indicateur **Total Dépenses** ;
- Liste et catégorisation des charges.

Les dépenses peuvent aussi être initiées via le module [Demandes & approbations](/modules/demandes-internes) selon votre organisation.
