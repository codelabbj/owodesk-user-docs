# Rapports

Onglet **Rapports** (`/app/treasury/reports`). Titre : **Rapports Trésorerie**.

## Sous-rapports

| Sous-onglet | Rôle |
|-------------|------|
| **Situation** | Photo de la trésorerie |
| **Flux de caisse** | Entrées / sorties sur la période |
| **Encaissements** | Détail des entrées |
| **Décaissements** | Détail des sorties |
| **Prévisions** | Projection |
| **Apports associés** | Suivi des apports |

Export **CSV** disponible selon le rapport.

:::info
Ce n’est **pas** la balance / grand livre comptable. Pour SYSCOHADA, voir [Comptabilité](/modules/comptabilite).
:::
