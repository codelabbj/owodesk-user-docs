# Activités

Onglet **Activités** (`/app/billing/activities`). Journal d’audit des actions du module Facturation.

:::info Propriétaire
Visible pour le **propriétaire** de l’organisation (et profils équivalents).
:::

## À quoi ça sert

Suivre les actions sensibles (création, finalisation, paiements, etc.) pour le contrôle et l’historique.

## Accéder à la page

Menu latéral **Facturation** → **Activités**.
