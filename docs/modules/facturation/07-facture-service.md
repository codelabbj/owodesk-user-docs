# Facture service

Onglet **Facture service** (`/app/billing/invoices/new-service`). Titre : **Facture prestation de service**.

Sert à facturer des **prestations / échéances de contrats** (module Services), **sans sortie de stock** produit.

## Accéder à la page

Menu latéral **Facturation** → **Facture service**, ou bouton **Facture service** depuis [Factures](/modules/facturation/factures).

## Contenu typique

Section **Prestations à facturer** :

| Colonne | Contenu |
|---------|---------|
| **Contrat** | Contrat de service lié |
| **Prestation** | Prestation / échéance |
| **Échéance** | Date |
| **Montant HT** | Montant à facturer |

Affichage éventuel des **impayés du client**.

## Création

1. Sélectionnez le client / les prestations à inclure.
2. Vérifiez les montants.
3. Cliquez **Créer la facture**.

Vous êtes ensuite renvoyé vers le [détail](/modules/facturation/factures#detail-dune-facture) pour finaliser et encaisser. Un lien vers le **contrat** peut apparaître sur la facture.

## Quand l’utiliser

- Abonnements ou prestations récurrentes déjà suivies dans Services ;
- Facturation d’échéances sans articles stock.

Pour vendre des produits physiques, utilisez [unientrepôt](/modules/facturation/facture-unientrepot) ou [multientrepôt](/modules/facturation/facture-multientrepot).
