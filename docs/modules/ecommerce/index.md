# E-commerce (Marketplace)

Le module **E-commerce** (`/app/ecommerce`) permet de publier une boutique sur la marketplace OwoDesk, synchroniser vos produits depuis le stock et traiter les **commandes initiées** (WhatsApp → facture).

Dans l’app : menu latéral **E-commerce** ; en-tête du module **Marketplace** — *Gérez votre boutique et vos produits sur la marketplace.*

| Onglet dans l’app | Documentation |
|-------------------|---------------|
| **Vue d'ensemble** | [Vue d'ensemble](/modules/ecommerce/vue-ensemble) |
| **Produits** | [Produits](/modules/ecommerce/produits) |
| **Commandes initiées** | [Commandes initiées](/modules/ecommerce/commandes-initiees) |
| **Paramètres** | [Paramètres boutique](/modules/ecommerce/parametres-boutique) |

## Parcours type

1. [Créez votre boutique](/modules/ecommerce/parametres-boutique) (identité, WhatsApp, carte, visuels).
2. Ajoutez des produits dans le [Stock](/modules/stock/produits), puis publiez-les dans [Produits](/modules/ecommerce/produits).
3. Suivez l’activité sur la [Vue d'ensemble](/modules/ecommerce/vue-ensemble).
4. Traitez les [commandes initiées](/modules/ecommerce/commandes-initiees) en facture brouillon.

## Prérequis

- Module **Stock** (produits / entrepôts) ;
- Module **Facturation** (traiter une intention en facture).

## Hors périmètre actuel

Pas d’onglets Catalogue, Livraison, Promos ou commandes e-commerce classiques : le parcours actuel est **boutique marketplace + intentions WhatsApp**.
