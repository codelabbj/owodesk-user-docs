# Lieux de travail

Onglet **Lieux de travail** (`/app/hr/work-locations`). Sites où les collaborateurs peuvent pointer (GPS et/ou QR).

## Accéder à la page

Menu latéral **RH** → **Lieux de travail**.

Vous pouvez aussi créer / assigner des lieux depuis le formulaire [employé](/modules/rh/employes), parfois à partir d’un **entrepôt Stock**.

## Ajouter un lieu

Bouton **Ajouter un lieu** :

| Élément | Description |
|---------|-------------|
| **Nom** | Ex. Siège, Magasin Cotonou |
| **Position** | Pointage sur la carte |
| **Rayon** | Zone de tolérance autour du point (mètres) |

## QR de pointage

Pour chaque lieu :

- **QR pointage** à afficher ou imprimer ;
- téléchargement / impression PDF ;
- **Régénérer le QR** si besoin de renouveler le code.

Les employés scannent le QR (ou pointent dans le rayon GPS) avec l’app / le parcours mobile, en utilisant aussi le **code organisation** de la page Employés.

## Lien avec le reste du RH

- Affectation des lieux sur la fiche employé ;
- Contrôle des pointages dans [Pointage](/modules/rh/presence) ;
- Cohérence possible avec les entrepôts du module Stock (création depuis un entrepôt existant).
