# Rapports équipe

Onglet **Rapports équipe** (`/app/hr/daily-reports`). Vue **management** des rapports journaliers rédigés par l’équipe.

## Accéder à la page

Menu latéral **RH** → **Rapports équipe**.

:::info Rédaction ailleurs
Les collaborateurs **rédigent** leur rapport dans **Projets → [Mon rapport](/modules/projets/mon-rapport)** (`/app/projects/daily-report`).
Cet écran RH sert à **consulter**, filtrer et (pour les admins) **corriger** les rapports de l’équipe.
:::

## Contenu typique

- Filtres par **collaborateur**, **jour** ou **période** ;
- Liste des rapports soumis ;
- Action **Voir** le détail ;
- Pour un administrateur : **Corriger le contenu** ou **Remettre en brouillon** (avec motif).

Lien utile : **Rédiger mon rapport** → ouvre Projets (composition du rapport du jour).

## Lien avec le pointage

Selon les paramètres entreprise (présence & rapports) :

- exiger le rapport **avant** de pointer le départ ;
- ou exiger d’avoir pointé le départ **avant** de soumettre le rapport.

Voir aussi [Pointage](/modules/rh/presence) et [Mon rapport](/modules/projets/mon-rapport).
