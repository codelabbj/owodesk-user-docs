# Activités

Onglet **Activités** (`/app/hr/activities`). Journal des actions récentes du module RH.

:::info Propriétaire
Cet onglet est visible pour le **propriétaire** de l'organisation (et profils équivalents).
:::

## À quoi ça sert

Consulter l'historique des actions sensibles ou importantes côté RH (paiements, pointages corrigés, validations, etc.), pour le suivi et l'audit.

## Accéder à la page

Menu latéral **RH** → **Activités**.
