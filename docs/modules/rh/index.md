# Ressources humaines

Le module **RH** (`/app/hr`) gère vos employés, la paie, le pointage, les horaires, les congés, les documents et les rapports d’équipe.

Ouvrez-le depuis le menu latéral **RH**. Le sous-menu reprend les onglets de l’application :

| Onglet dans l’app | Documentation |
|-------------------|---------------|
| **Employés** | [Employés](/modules/rh/employes) |
| **Gestion de la paie** | [Gestion de la paie](/modules/rh/paie) |
| **Pointage** | [Pointage](/modules/rh/presence) |
| **Rapports équipe** | [Rapports équipe](/modules/rh/rapports-equipe) |
| **Horaires** | [Horaires](/modules/rh/horaires) |
| **Lieux de travail** | [Lieux de travail](/modules/rh/lieux-de-travail) |
| **Congés/Permissions** | [Congés et permissions](/modules/rh/conges-permissions) |
| **Demandes de pièces** | [Demandes de pièces](/modules/rh/demandes-pieces) |
| **Documents** | [Documents](/modules/rh/documents) |
| **Activités** | [Activités](/modules/rh/activites) (propriétaire) |

L’ouverture du module redirige vers **Employés** (`/app/hr/employees`).

## Parcours type

1. Créez vos [employés](/modules/rh/employes), leurs [lieux de travail](/modules/rh/lieux-de-travail) et leurs [horaires](/modules/rh/horaires).
2. Suivez le [pointage](/modules/rh/presence) et traitez les [congés / permissions](/modules/rh/conges-permissions).
3. Consultez les [rapports d’équipe](/modules/rh/rapports-equipe) (la rédaction se fait dans [Projets → Mon rapport](/modules/projets/mon-rapport)).
4. Générez et payez les salaires via la [gestion de la paie](/modules/rh/paie).
5. Centralisez les [documents](/modules/rh/documents) et les [demandes de pièces](/modules/rh/demandes-pieces).

## Centre d’aide intégré

Le bouton d’aide / guide en haut du module rappelle le rôle de chaque section.
