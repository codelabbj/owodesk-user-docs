# Poser une question à Owo

## Ouvrir le panneau (recommandé)

1. Cliquez sur le bouton **robot** en bas à droite (libellé **Owo**).
2. Un panneau s’ouvre à droite.
3. **Échap** ferme le panneau.

En-tête : titre **Owo**, discussion active (ou **Sans titre**), aide **?**.

Actions du panneau :

| Bouton | Effet |
|--------|-------|
| **Nouvelle discussion** | Nouveau fil |
| **Historique** | Liste des conversations (vide : *Aucune discussion pour l’instant.*) |
| **Supprimer** | Efface la discussion active (confirmation) |

<DocImage src="/img/guides/assistant-owo/panneau-owo.png" alt="Panneau de discussion de l'assistant Owo" />

## Premier message

Accueil type :

- **Par où commencer ?**
- *Écrivez votre question ci-dessous : une nouvelle conversation sera ouverte automatiquement au premier envoi…*
- Placeholder : *Posez votre première question pour ouvrir une discussion…*
- Hint : **Entrée** pour envoyer · **Maj+Entrée** pour une nouvelle ligne

Exemples :

- Combien de contacts avons-nous dans le CRM ?
- Quelles factures sont impayées ce mois-ci ?
- Quels produits sont en alerte de stock ?

## Pendant et après la réponse

1. Pendant l’attente : **L'assistant réfléchit**.
2. Puis la réponse apparaît en une fois (texte dans la bulle).
3. Placeholder suivant : *Votre message…*
4. Pendant la génération, l’icône d’envoi devient un **carré** pour interrompre.

Le titre du fil est souvent déduit du début de votre première question.

Vous pouvez enchaîner (*Et pour le mois dernier ?*, *Peux-tu détailler ?*).

<DocImage src="/img/guides/assistant-owo/reponse-owo.png" alt="Réponse de l'assistant Owo" />

## Supprimer une discussion

**Supprimer** → confirmation **Supprimer cette conversation ?** (*Tous les messages… seront définitivement effacés.*)

## Page `/app/assistant`

Même assistant en pleine page (titre **Owo**, liste de fils à gauche si vous en avez). Moins d’actions « Historique / Supprimer » que le panneau flottant : privilégiez le FAB pour gérer les fils.

## Widget sur la landing OwoDesk (public)

Sur le **site public** OwoDesk (pas votre boutique) :

- FAB **Owo** / **Demander à Owo** ;
- suggestions (modules, prix, démarrage) ;
- limite typique **20 messages** par session ;
- réponses générales produit (pas les données de votre ERP) ;
- CTA possible **Créer un compte gratuit**.

Ce widget n’est **pas** un composant à installer sur le site de votre entreprise.
