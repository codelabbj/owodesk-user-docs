# Mon rapport

Onglet **Mon rapport** (`/app/projects/daily-report`). Permet de rédiger le **rapport du jour** à partir des tâches que vous avez terminées.

Sous-titre dans l’app : *Rédigez votre rapport du jour à partir de vos tâches terminées.*

## Accéder à la page

Menu latéral **Projets** → onglet **Mon rapport**.

Cet écran est accessible depuis le module Projets, **sans nécessairement avoir des droits RH**. Les managers peuvent ensuite consulter les rapports côté RH selon la configuration de l’entreprise.

## Contenu de l’écran

| Zone | Description |
|------|-------------|
| **Tâches terminées aujourd’hui** | Liste des tâches passées à **Terminé** aujourd’hui ; elles **préremplissent** le brouillon |
| Zone de rédaction | Texte du rapport (brouillon modifiable) |
| **Soumettre** | Envoie le rapport du jour |
| **Mes derniers rapports** | Historique de vos rapports déjà envoyés |

Si aucune tâche n’est terminée aujourd’hui, la liste est vide : vous pouvez quand même rédiger manuellement.

## Parcours type

1. Terminez vos tâches dans l’onglet [Tâches](/modules/projets/taches) au fil de la journée.
2. Ouvrez **Mon rapport**.
3. Vérifiez le texte prérempli, complétez ou corrigez.
4. Cliquez sur **Soumettre**.

Une fois soumis, un message du type **Rapport du jour soumis** confirme l’enregistrement.

## Lien avec la présence (RH)

Selon les paramètres de l’entreprise, le rapport journalier peut être lié au pointage :

- exiger le rapport **avant** de pointer le départ ;
- ou exiger d’avoir pointé le départ **avant** de pouvoir soumettre le rapport.

Ces règles se configurent côté administration / RH (présence & rapports), pas dans cet écran.

## Bon à savoir

- Le rapport se rédige ici ; la **consultation d’équipe** se fait en général dans le module RH.
- Corriger un rapport déjà soumis peut être limité dans le temps (fenêtre courte côté RH, selon la config).
