# Projets

Le module **Projets** (`/app/projects`) sert à suivre le travail d’équipe : projets, tâches sur un tableau Kanban, rapport du jour et droits de visibilité.

Ouvrez-le depuis le menu latéral **Projets**. Le sous-menu reprend les onglets de l’application :

| Onglet dans l’app | Documentation |
|-------------------|---------------|
| **Tâches** | [Tâches](/modules/projets/taches) |
| **Mon rapport** | [Mon rapport](/modules/projets/mon-rapport) |
| **Autorisations** | [Autorisations](/modules/projets/autorisations) |

L’ouverture du module redirige vers **Tâches** (`/app/projects/tasks`).

## Parcours type

1. [Créez un projet](/modules/projets/taches#creer-un-projet) (nom + description).
2. Ajoutez des [tâches](/modules/projets/taches) dans les colonnes **À faire**, **En cours**, **Terminé**.
3. Assignez des collaborateurs, commentez et suivez les échéances.
4. Pour un travail qui se répète, activez **Tâche récurrente** à la création.
5. En fin de journée, rédigez [Mon rapport](/modules/projets/mon-rapport) à partir des tâches terminées.
6. Si besoin, élargissez la [visibilité des tâches](/modules/projets/autorisations) pour certains collaborateurs.

## Centre d’aide intégré

Le bouton **Comprendre le module** (guide) rappelle les concepts projets et tâches (création, assignation, échéances).

## Limites actuelles de l’interface

- Création de projet limitée à **Nom** et **Description** (pas de budget, chef de projet ni dates dans l’écran actuel).
- Les **tâches récurrentes** se configurent uniquement à la **création** : pas d’écran pour pause / modification du modèle ensuite.
- Le Kanban est pensé pour un usage **tablette paysage / bureau** (pas pleinement adapté au téléphone en portrait).
